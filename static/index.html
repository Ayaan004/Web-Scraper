Getting Started

1

Enter URL

Type or paste the URL of the website you want to scrape. The system will automatically add https:// if not provided.

2

Select Scrape Type

Choose what data you want to extract: complete scrape, text only, links, images, headings, meta tags, tables, or use a custom CSS selector.

3

Scrape & Analyze

Click "Scrape Now" and view organized results in tabs. Export as JSON or copy to clipboard for further use.

API Endpoint

POST /api/scrape
Content-Type: application/json

{
  "url": "https://example.com",
  "type": "all",
  "selector": ".class-name"  // optional
}

Response includes status code, timestamp, extracted data organized by type, and scrape time.
